# app/memory/persistent_checkpoint.py 的 LocalFileSaver 继承全局 InMemorySaver，
# 只在写操作后把状态原子落到本地 JSON 文件：进程重启可读、多实例可共享（同机/共享盘），
# 因此 requirements.txt 不需要新增任何依赖，也不会污染全局环境。
#
# 官方 SqliteSaver 是可选增强，不是主依赖：本机按隔离要求装到了 .p1deps，
# 命令（不装进全局 site-packages）：
#   python -m pip install --target .p1deps langgraph-checkpoint-sqlite
# 运行时由 app/memory/persistent_checkpoint.py 自动把 .p1deps 追加到 sys.path 末尾。
# 注意：该包依赖 langgraph-checkpoint>=4.3，而当前全局是 4.0.1，混用会版本错配，
# 因此默认不启用；显式 CHECKPOINT_BACKEND=sqlite 时若加载失败会自动降级并打 WARN。
