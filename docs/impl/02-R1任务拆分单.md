## 2. 并行与门禁

- **第一批并行**：R1-00 完成后，R1-01 / R1-02 / R1-04 同时开工；R1-06 / R1-07 也同时开工（契约已冻结，不阻塞）。
- **第二批**：R1-03 依赖 R1-02 的订单行模型；R1-05 依赖 R1-01 的商品契约。
- **门禁**：R1-08 只在 R1-01~07 全部 terminal 后开始；任一任务 `mvn verify` 红即不得进入验收。
