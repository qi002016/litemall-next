## 通用约定

### 统一返回结构



```
{

\&#x20; "code": 200,

\&#x20; "msg": "成功",

\&#x20; "data": {}

}
```



| 字段   | 类型     | 说明               |
| ---- | ------ | ---------------- |
| code | int    | 200 = 成功；非 200 = 错误码 |
| msg  | string | 提示信息，可直接展示       |
| data | any    | 业务数据，失败为 null    |

### 请求头



| Header        | 必填    | 说明                 |
| ------------- | ----- | ------------------ |
| Authorization | 登录后必填 | `Bearer {token}`   |
| Content-Type  | 是     | `application/json` |

### 分页约定

GET 请求带 query 参数:



| 参数       | 类型     | 默认      | 说明          |
| -------- | ------ | ------- | ----------- |
| pageNum  | int    | 1       | 页码，从 1 开始   |
| pageSize | int    | 10      | 每页条数，最大 100 |
| sort     | string | addTime | 排序字段        |
| order    | string | desc    | asc/desc    |

分页响应:



```
{

\&#x20; "list": \\\[],

\&#x20; "total": 123,

\&#x20; "pageNum": 1,

\&#x20; "pageSize": 10,

\&#x20; "pages": 13

}
```

### 错误码总表



| code | 说明            |
| ---- | ------------- |
| 200  | 成功            |
| 400  | 参数校验失败 / 业务错误 |
| 401  | 未登录或 token 过期 |
| 403  | 无权限 / 账号冻结注销  |
| 500  | 服务器内部错误       |

服务段错误码格式：1xxxx=user, 2xxxx=goods, 3xxxx=marketing, 4xxxx=order, 5xxxx=pay, 6xxxx=message, 7xxxx=storage

# 一、user 服务 (端口 8001)

## 1.1 用户登录



* **URL**:`/app/auth/login`

* **Method**:`POST`

* **鉴权**: 白名单

**请求体:**



| 字段       | 类型     | 必填 | 说明               |
| -------- | ------ | -- | ---------------- |
| username | string | 是  | 用户名              |
| password | string | 是  | 密码 (明文，HTTPS 传输) |

**请求示例:**



```
{ "username": "zhangsan", "password": "123456" }
```

**响应 data:**



| 字段       | 类型     | 说明        |
| -------- | ------ | --------- |
| userId   | long   | 用户 ID     |
| username | string | 用户名       |
| token    | string | JWT token |

**响应示例:**



```
{

\&#x20; "code": 200,

\&#x20; "msg": "成功",

\&#x20; "data": { "userId": 1, "username": "zhangsan", "token": "eyJhbGci..." }

}
```



***

* **鉴权**: 需登录

**Form 参数:**



| 字段   | 类型   | 必填 | 说明           |
| ---- | ---- | -- | ------------ |
| file | file | 是  | 文件 (图片 / 文档) |

**请求示例:**



```
curl -X POST http://localhost:8007/app/storage/upload \\\\

\&#x20; -H "Authorization: Bearer {token}" \\\\

\&#x20; -F "file=@/Users/xxx/avatar.png"
```

**响应 data:**



| 字段   | 类型     | 说明        |
| ---- | ------ | --------- |
| url  | string | 文件访问 URL  |
| name | string | 文件名       |
| size | long   | 文件大小 (字节) |
